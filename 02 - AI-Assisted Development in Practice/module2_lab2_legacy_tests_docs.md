# Module 2 — Lab 2: Legacy Code Explanation, Tests, and Docs

## 

## Goal

Practice AI-assisted work on existing code rather than only greenfield generation.

## Source file

```text
work\_items\_api\_starter/lab2\_assets/legacy\_work\_item\_logic.py
```

## Tasks

1. Ask AI for a read-only explanation.
2. Challenge vague or overconfident claims.
3. Ask for edge cases.
4. Generate pytest tests.
5. Review and improve the tests.
6. Draft documentation that matches actual behavior.
7. Optional: propose a safe refactor plan without implementing it.

## Prompt sequence

### 1\. Read-only explanation

```text
Explain this module for a new team member.
Focus on actual behavior and edge cases.
Do not suggest changes yet.
Base your explanation only on the visible code.
```

### 2\. Challenge assumptions

```text
Which of your claims are directly visible in the code, and which are assumptions?
```

### 3\. Test generation

```text
Write pytest tests for the most important behaviors.
The tests should prove behavior, not implementation details.
Use explicit assertions and cover aliases, missing due dates, done items, date parsing, and malformed date input.
```

### 4\. Test review

```text
Review these tests as if they were generated by AI.
Which tests are weak, redundant, misleading, or missing important assertions?
Suggest improvements.
```

## Suggested solution

The solution tests are included in:

```text
work\_items\_api\_solution/tests/test\_legacy\_work\_item\_logic.py
```

Expected test themes:

* aliases normalize to canonical statuses;
* unknown statuses pass through unchanged;
* missing due dates are not overdue;
* unfinished past-due items are overdue;
* done items are not overdue even when due date is in the past;
* date-only strings are interpreted as midnight;
* malformed dates raise `ValueError`.

Example documentation note:

```text
normalize\_status(raw) converts common status aliases into canonical work-item statuses.
Unknown statuses are returned after basic normalization.

is\_overdue(item, now=None) checks due\_at or due\_date and returns True only when the item is not done and the due date is earlier than now. It accepts datetime values, ISO datetime strings, and date-only strings. It does not recover from malformed date strings.
```
