# AI Working Agreement

Use AI to accelerate development, not to outsource ownership.

## Allowed

- Planning implementation slices.
- Explaining unfamiliar code.
- Drafting tests and documentation.
- Reviewing diffs as a second pass.
- Drafting API clients that are manually reviewed.

## Not allowed

- Accepting generated code without reading it.
- Deleting tests to make the suite pass.
- Changing public response shapes without explicit approval.
- Pasting secrets, tokens, credentials, customer data, or proprietary logs.
- Letting an agent deploy or modify production resources.

## Required before done

- Passing tests.
- Manual diff review.
- Prompt log or short reflection.
- One accepted/rejected AI suggestion noted.
