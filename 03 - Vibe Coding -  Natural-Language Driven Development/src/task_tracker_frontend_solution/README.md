# Task Tracker Frontend — Solution

Reference solution for Module 3.

## Run

```bash
npm install
npm test
npm run serve
```

## What this solution demonstrates

- local-first task tracker frontend;
- safe DOM rendering;
- pure state helpers with tests;
- small API client for the Module 2 Work Items API;
- local/API mode switch;
- error handling for unavailable API;
- enough structure to be owned and extended.

## Optional API integration

Start the Module 2 API solution at `http://127.0.0.1:8000`, then enter that URL in the frontend API field and click **Connect API**.
